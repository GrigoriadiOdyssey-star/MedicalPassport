# Безопасность EDHT

Сейчас EDHT — спецификации, реестр и проверяющие скрипты. Публичного приложения, production-окружения и подтверждённого соответствия стандартам в этой поставке нет.

Обнаруженный секрет сначала отзывают у поставщика, затем удаляют из рабочей версии и согласуют очистку истории; удаление файла само по себе не отзывает секрет. Данные о возможной уязвимости передают владельцу приватного проекта через согласованный закрытый канал. Не помещайте персональные или медицинские данные в общедоступные issues.

До пилота должны быть назначены ответственные и канал сообщений об инцидентах. Конкретные требования описаны в [клинической безопасности](docs/safety/clinical-safety.md), [приватности](docs/safety/privacy-and-consent.md), [авторизации](docs/engineering/auth-and-qr.md) и [эксплуатации](docs/engineering/operations.md).
