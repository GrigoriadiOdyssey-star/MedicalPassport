# MASTER-08 reference review

Consulted 2026-09-15: [FHIR R4 security](https://hl7.org/fhir/R4/security.html), [FHIR R4 Consent](https://hl7.org/fhir/R4/consent.html), [OAuth Security BCP RFC 9700](https://www.rfc-editor.org/rfc/rfc9700.html). FHIR R4 is a proposed optional mapping baseline, not a newest-release or conformance claim. FHIR resource/consent representation does not supply authorization enforcement; identity and access policies require separate contracts. OAuth BCP is a design review reference, not implementation certification.

No clinical anesthetic dose, airway threshold, recovery protocol, device support or legal compliance was validated. Those require current partner/intended-use evidence and qualified approval.
