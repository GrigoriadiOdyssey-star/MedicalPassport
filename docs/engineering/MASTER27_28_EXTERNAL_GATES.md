# MASTER-27/28 external gates

The demonstrable MVP may expose interfaces and synthetic adapters for the following, but must not claim production readiness until a real provider and validation evidence exist:

- Production FHIR server connectivity (Observation / DiagnosticReport / ServiceRequest)
- OCR / laboratory document extraction
- APNs / FCM or other external push infrastructure
- Certified medical translation provider
- National/regional EHR connectivity
- Real pharmacy inventory and fulfillment
- Payment/acquiring
- Telemedicine video provider
- Device/wearable provider integrations
- Production identity/eID provider

These gates do not block a synthetic demonstrable MVP. They do block corresponding production claims.
