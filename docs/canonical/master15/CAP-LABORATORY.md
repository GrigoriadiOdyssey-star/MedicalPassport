# CORE-CAP-LABORATORY — consolidated source profiles

Extends existing canonical owner and all prior addenda. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## laboratory

Laboratory owns attributed specimen/result/assay records and their revisions. Biomarker names, methods, reference intervals, genomic findings and experimental markers remain source-scoped; no universal reference range or clinical validity is inferred.

Acceptance additions: Retain method, specimen, time, unit, reference-population and verification context; amended results invalidate downstream interpretations. Genomic and experimental biomarker profiles require separate qualified applicability review.
