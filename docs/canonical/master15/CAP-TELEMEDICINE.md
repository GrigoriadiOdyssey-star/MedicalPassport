# CORE-CAP-TELEMEDICINE — consolidated source profiles

Extends existing canonical owner and all prior addenda. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## telemedicine

Telemedicine owns the authorized remote encounter/session and communication lifecycle. Specialty profiles retain video, counseling, image review and monitoring inputs. Medication changes, emergency decisions, devices, record truth and prescribing remain with their domain authorities.

Acceptance additions: Preserve guardian/confidential access, location/licensure context, recording consent, source timestamps and connectivity failures. No remote signal or delivered message establishes safe triage, therapy adjustment or an attended consultation.
