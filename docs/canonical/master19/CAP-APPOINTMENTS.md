# CORE-CAP-APPOINTMENTS — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. Previously inactive registered owners receive their first source-preserving specification without creating a new architecture owner. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## laboratory-collection-booking

Appointments owns home-collection requests and confirmed slots. Service area, staff availability and patient consent must be checked; a request is not collection or laboratory acceptance.

Acceptance additions: Preserve every original clause, patient/tenant/source/version/time provenance and explicit missingness. Test wrong identity, stale measurements, revoked consent, guardian changes, adolescent confidentiality and source corrections. Pediatric age, developmental stage, weight/height/unit/time and clinical context remain explicit where applicable. No automatic diagnosis, prescription, dose change, medication stop, device actuation or crisis disposition; qualified clinician review remains required. Clinical validation and production acceptance remain external gates.

## core-appointments-and-marketplace

Appointments owns service discovery-to-booking handoff, requested versus confirmed slots and hospital selection preferences. Advertised services, prices and provider availability are source/time-bound, not clinical recommendation or guaranteed booking.

Acceptance additions: Preserve every original clause, patient/tenant/source/version/time provenance and explicit missingness. Test wrong identity, stale measurements, revoked consent, guardian changes, adolescent confidentiality and source corrections. Pediatric age, developmental stage, weight/height/unit/time and clinical context remain explicit where applicable. No automatic diagnosis, prescription, dose change, medication stop, device actuation or crisis disposition; qualified clinician review remains required. Clinical validation and production acceptance remain external gates.

## Source scope

- Original 366 / laboratory-collection-booking: Laboratory Home Collection — Displays laboratories offering home specimen collection.
- Original 108 / core-appointments-and-marketplace: Appointment Management — Coordinate physician selection, booking, reminders, visits, summaries and follow-up.
- Original 330 / core-appointments-and-marketplace: Medical Services Marketplace — Provides centralized access to available healthcare services.
- Original 757 / core-appointments-and-marketplace: Delivery Hospital Selection — Allows comparison of maternity hospitals.
