# CORE-CAP-INTEROP — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. Previously inactive registered owners receive their first source-preserving specification without creating a new architecture owner. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## pediatric-vaccine-exchange

Interoperability owns adverse-event reporting and immunization/certificate exchange. Versioned authority-specific mappings, mandatory fields, submission state, correction lineage and acknowledgement are separate from clinical source truth. A submission is not acceptance or causal attribution.

Acceptance additions: Preserve every original clause, patient/tenant/source/version/time provenance and explicit missingness. Test wrong identity, stale measurements, revoked consent, guardian changes, adolescent confidentiality and source corrections. Pediatric age, developmental stage, weight/height/unit/time and clinical context remain explicit where applicable. No automatic diagnosis, prescription, dose change, medication stop, device actuation or crisis disposition; qualified clinician review remains required. Clinical validation and production acceptance remain external gates.

## Source scope

- Original 4344 / pediatric-vaccine-exchange: Vaccine Adverse Event Reporting Gateway — Supports jurisdiction-specific adverse-event reporting workflows.
- Original 4349 / pediatric-vaccine-exchange: Global Vaccination Interoperability Gateway — Connects EDHT vaccination records with authorized external health systems.

- Original 202 / remaining-platform-exchange: Partner Ecosystem Architecture — Single integration model.

- Original 209 / remaining-platform-exchange: Developer Platform — Allows certified partners to build integrations.
- Original 211 / remaining-platform-exchange: Global Healthcare Gateway — Unified gateway connecting Medical Passport Platform with national and international healthcare systems.
- Original 213 / remaining-platform-exchange: International Medical Standards — Provides standardized medical terminology.
- Original 214 / remaining-platform-exchange: Laboratory Integration Hub — Compatible with public and private laboratories.
- Original 216 / remaining-platform-exchange: International ePrescription Hub — Patient consent required before sharing.
- Original 66 / core-interoperability-and-national-exchange: National Health Systems Integration — Defines integration with national electronic health record systems and government healthcare platforms.
- Original 67 / core-interoperability-and-national-exchange: European Health Data Space (EHDS) Integration — Defines integration with the European Health Data Space (EHDS) to enable secure cross-border exchange of medical information across EU member states.
- Original 450 / core-interoperability-and-national-exchange: Dental Laboratory Integration — Supports interaction with dental laboratories.
