# CORE-CAP-ADMINISTRATION — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. All owners already have canonical specifications. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## administration-log-profile

Administration owns attributed actual medication-administration history and correction lineage. A prescription, dispensing record, reminder or patient intention does not prove administration.

Acceptance additions: Preserve performer/reporting source, actual versus reported status, product/dose/route/time and omissions. Corrections append provenance; duplicates, missing identity and conflicting exposure times cannot silently add an administered dose.

## Source scope

- Original 432 / administration-log-profile: Medication Administration Log — Stores records of medication administration.
