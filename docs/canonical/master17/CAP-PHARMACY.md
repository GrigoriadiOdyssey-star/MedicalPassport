# CORE-CAP-PHARMACY — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. All owners already have canonical specifications. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## pharmacy-availability-profiles

Existing Pharmacy owns pharmacy-specific availability and shortage projections. Product identity stays Medication; inventory facts retain supplier/branch/source/time. Predictive shortage estimates are derived evidence, not current guaranteed stock.

Acceptance additions: Preserve geography, product/form/package, inventory timestamp, source and forecast uncertainty. Stale or unavailable feeds display unknown status; stock/shortage projections cannot authorize substitution, reservation or dispense.

## Source scope

- Original 152 / pharmacy-availability-profiles: Medicine Availability Engine — AI predicts shortages.
- Original 154 / pharmacy-availability-profiles: Drug Shortage Monitoring — Monitor pharmaceutical supply sources and flag shortage and alternative-supply candidates.
