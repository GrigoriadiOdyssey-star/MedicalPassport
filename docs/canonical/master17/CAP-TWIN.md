# CORE-CAP-TWIN — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. All owners already have canonical specifications. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## twin-remaining-projections

Existing Twin owns versioned source-scoped simulations and longitudinal projections. Patient, organ, physician, hospital and population subject kinds remain explicit and separate. Clinical records, professional identity, organizational operations and research data retain their own authoritative owners; none can be overwritten by a simulation.

Acceptance additions: Retain subject kind/binding, observed versus simulated states, assumptions, input/model/scenario versions, uncertainty and valid-use domain. Source correction or permission changes invalidate dependent projections. No treatment, staffing or coercive action is authorized by a projected outcome.
