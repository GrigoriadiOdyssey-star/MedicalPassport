## emergency-qr-profile

Existing QR owns the bounded emergency access reference lifecycle; Emergency owns the permitted clinical summary and Security owns enforcement. A scanned code does not independently grant full-record or clinical-action authority.

Acceptance additions: Bind permitted resources/recipient/purpose/expiry and require current revocation checks where online. Reject replay, cross-patient use and widened scopes. Offline revocation guarantees cannot be invented; fallback behavior requires explicit separate approval.
