# CORE-CAP-DOCUMENTS — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. All owners already have canonical specifications. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## precision-genomic-report

Documents owns derived physician and patient genomic report versions with source references and audience-specific disclosure. A summary does not establish variant pathogenicity, diagnosis or permission to disclose relatives information.

Acceptance additions: Preserve every source clause with source-specific applicability, patient/tenant identity, evidence versions, uncertainty and correction lineage. Unverified or stale context must remain explicit; never infer absent disease, permission or clinical eligibility. Test wrong-patient, revoked consent, missing inputs, conflicting sources and downstream invalidation. Qualified clinical acceptance and actual service integration remain required.

## ai-clinical-document-drafts

Documents owns attributed drafts of medical notes, discharge/referral/certificate/report documents and translations. Audio-derived text and translation retain provenance, language, uncertainty and human correction. Generated certificate or impression is not signed clinical attestation.

Acceptance additions: Preserve every source clause with source-specific applicability, patient/tenant identity, evidence versions, uncertainty and correction lineage. Unverified or stale context must remain explicit; never infer absent disease, permission or clinical eligibility. Test wrong-patient, revoked consent, missing inputs, conflicting sources and downstream invalidation. Qualified clinical acceptance and actual service integration remain required. Require permitted recording, minimum retention, original/draft/signed state separation, qualified verification before release, and no unattended signing or hallucinated findings.
