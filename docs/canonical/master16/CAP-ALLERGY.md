# CORE-CAP-ALLERGY — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. For Pharmacy this is the first canonical specification under the already registered owner, not a new architecture. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## allergy-profiles

Existing Allergy owns source-scoped allergy/hypersensitivity assertions, verification and reaction context; specialty care, diagnostic challenge, desensitization and treatment remain governed workflows. Vaccine adverse events and temporal associations do not automatically create allergy or contraindication. Existing vaccine and medication owners remain authoritative for their records.

Acceptance additions: Preserve suspected versus confirmed, absent versus unknown/not assessed, culprit product/substance, reaction time, severity and reporting source. Delabeling requires attributed specialist disposition and reversible correction history; display must not silently broaden a class restriction.
