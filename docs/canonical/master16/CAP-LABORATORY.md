# CORE-CAP-LABORATORY — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. For Pharmacy this is the first canonical specification under the already registered owner, not a new architecture. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## laboratory-centers

Extend existing Laboratory with source-specific result-center profiles. Store attributed specimens, assays, units, methods, reference intervals and revisions; hormonal, immune, microbiology and pediatric context remain separate. A center does not own clinical interpretation or medication selection.

Acceptance additions: Preserve collection/result/correction times, method/unit and age/pregnancy reference population; invalidate downstream derived interpretations on amendment. Missing, preliminary and negative results must remain distinguishable.
