# CORE-CAP-DEVICES — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. For Pharmacy this is the first canonical specification under the already registered owner, not a new architecture. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## device-integration-profiles

Existing Devices owns versioned device data and connection evidence for CGM, insulin pumps, automated insulin delivery and smart inhalers. Clinician-defined therapy and approved device functionality remain external authorities. EDHT documentation integration does not establish a command channel, compatible device release or regulated treatment authorization.

Acceptance additions: Preserve device identity/release, units, clock offsets, quality flags and disconnect state. Test stale/replayed/cross-patient data, duplicate readings and revoked connections. No automated EDHT insulin or inhaler setting change is authorized; any future command profile requires its own complete safety/compatibility and clinician authorization contract.

## Source scope

- Original 4139 / device-integration-profiles: Pediatric Continuous Glucose Monitoring Integration Module — Integrates continuous glucose monitoring data.
- Original 4140 / device-integration-profiles: Pediatric Insulin Pump Integration Module — Supports insulin delivery device integration.
- Original 4141 / device-integration-profiles: Pediatric Automated Insulin Delivery Integration Module — Supports integration with compatible automated insulin delivery systems.
- Original 4492 / device-integration-profiles: Pediatric Smart Inhaler Integration Module — Integrates compatible connected inhaler systems.
