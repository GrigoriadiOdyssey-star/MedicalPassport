# CORE-CAP-CDS — consolidated source profiles

Uses an existing registered canonical owner and preserves all prior addenda. For Pharmacy this is the first canonical specification under the already registered owner, not a new architecture. Every clause below applies only to its listed source profiles; it is not a universal clinical rule. No new service, clinical approval or implementation readiness.

## clinical-ai-decision-profiles

Existing CDS owns the clinician-facing decision artifact and attributed human disposition; AI owns model execution, Twin owns simulations, and clinical source owners retain facts and treatment authority. Shared clinical decision support is not interchangeable evidence across pediatric, genomic, ICU, mental-health or imaging tasks.

Acceptance additions: Preserve each original intended population/task, model/evidence/source versions, uncertainty and abstention. Require age/skin-tone/device/cohort-specific evaluation where applicable, correction/revocation propagation and clinician review. Never infer undocumented trauma, autonomously diagnose, change therapy/device settings, coerce care or exclude acute disease from a score or summary.
